# SMOKE.md — чек-лист ручной проверки перед релизом

Запускается перед каждым выпуском (`/prepare-release`). Каждый пункт — ~1 минута.
Провал любого пункта — стоп-релиз.

## Запуск

- [ ] Лаунчер стартует, все поля вкладок Models и SSH читаются из сохранённых настроек
- [ ] Запустить, закрыть, запустить снова — настройки на месте

## Агент и профили

- [ ] Локальный запуск: отправить запрос агенту → приходит ответ
- [ ] Профиль с некорректным ключом: понятная ошибка, **без секретов в тексте**
- [ ] Профиль с отсутствующим ключом: `no API key found`, имя профиля читаемо
- [ ] Два профиля LLM: запрос на первом, `Ctrl+L`, запрос на втором → оба отвечают

## SSH и транспорт

- [ ] `!ssh user@host` → подключение, `Ctrl+P` → ввод пароля → агент выполняет команду на удалёнке
- [ ] Настроить SSH-профиль в лаунчере → Launch → `config.toml` содержит `[[ssh_targets]]`
- [ ] `Ctrl+O` → оверлей выбора хоста → `↑↓` навигация → `Enter` → подключение → `Ctrl+T` на том же хосте; `Esc` → отмена
- [ ] Команда с подтверждением: диалог Approve/Deny, клик по кнопке, Enter = выбрать выделенную
- [ ] Деструктивная команда: подсвечена `danger`, требует подтверждения

## Интерактивный терминал

- [ ] `Ctrl+T` → открывается терминал → ввод работает → вывод появляется
- [ ] Прокрутка колесом / PgUp/PgDn в терминале → scrollback работает
- [ ] `Ctrl+T` повторно → возврат к агенту, терминал жив

## Вкладки

- [ ] `Ctrl+N` → новая вкладка, всегда local
- [ ] `Ctrl+Tab` / `Ctrl+1..9` → переключение без артефактов
- [ ] `Ctrl+W` → закрыть вкладку; последняя → выход
- [ ] Маркеры активности: `●` (работает), `?` (ждёт подтверждения), `○` (новый вывод)

## Интерфейс

- [ ] `F1` → оверлей справки открывается и прокручивается PgUp/PgDn
- [ ] Вставка из буфера (`Ctrl+V`) в поле ввода агента
- [ ] Мышь: скролл чата колесом, клик по `↓ N new` → пролистывание вниз
- [ ] Выделение мышью → копирование в буфер → тост `· copied`
- [ ] Команды сворачиваются/разворачиваются по клику
- [ ] Help-бар внизу показывает горячие клавиши текущего режима
- [ ] `Ctrl+L` циклит профили, статус-бар показывает токены

## Сессии

- [ ] Выход (`Ctrl+Q`) → сессия сохранена
- [ ] Повторный запуск с `--session <id>` → история чата, вкладки, ввод восстановлены
- [ ] История ввода агента (Up/Down) переживает перезапуск
